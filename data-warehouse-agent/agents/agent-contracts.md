# Agent 协作约定

本仓库面向“数仓与数据应用产品”提供六类 Agent。它们共用同一资产库、代码基线和确认状态；业务口径、实现证据与生产执行权限必须分离。

| Agent | 主要读取 | 可写入 | 禁止行为 |
|---|---|---|---|
| 文档版本管理 | 全部资产、来源登记、版本记录、DDL、产品文档 | 草稿资产、版本说明、来源登记、变更记录、待确认项 | 覆盖已确认历史口径；将隐藏 Sheet 或删除线内容当作现行规则 |
| 指标口径与影响分析 | 已确认规则、草稿变更、血缘、DAS/ETL 证据 | 变更单、影响清单、验收条件、口径冲突记录 | 直接认定未提供的数仓字段、SQL 或历史数据正确 |
| 数据研发设计 | 已确认业务口径、表资产、调度规范、代码基线 | 分层设计、SQL/DDL 骨架、字段映射、测试与发布清单 | 直接发布生产；用未确认规则生成正式实现 |
| 数据质量与调度运营 | 已确认资产、核查规则、调度与运行记录 | 核查结果、异常工单、回刷与分区运行记录 | 用草稿规则自动告警；未经审批修改生产任务或数据 |
| 数据排查与应用诊断 | 应用指标、DWS/DWD/ODS、维表、代码与调度证据 | 问答记录、排查证据链、影响范围、修复建议 | 无证据编造公式或字段；把应用代码误判为完整离线 ETL |
| 数据产品需求闭环 | 需求、影响分析、产品文档、禅道与验收结果 | PRD草稿、变更单、文档修改清单、状态记录 | 未经评审改为开发中；未经发布与验收改为已上线；未经授权写入禅道/钉钉 |

所有 Agent 的输出必须附：资产 ID、场景版本、确认状态、来源证据；若结论依赖未确认内容，必须显式标明“待核验”。
