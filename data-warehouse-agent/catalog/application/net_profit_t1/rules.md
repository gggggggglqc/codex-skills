# T+1 净利规则（V6.4.9.3 文档）

## 三张净利事实

| 表 | 作用 |
|---|---|
| `doris_app_net_profit_check_report_v2` | SKU/供应商粒度的收入、成本、业务费用及编码事实；国内与跨境收入成本进入该表 |
| `dp_dws.doris_dws_finance_cost_sbjct` | 科目费用分摊成功事实 |
| `dp_dws.doris_dws_finance_cost_sbjct_failure` | 费用无法关联或分摊基数为 0 的失败事实；跨境失败数据保留非 CN 国别 |
| `dp_dws.doris_app_finance_profit_business` | 基于上述三张事实生成科目化净利指标，供老板报表弹窗/多维净利使用 |

## 净利指标

- 考核净利 = 不含税收入 − 成本 − 费用 − 税金及附加 + 营业外收入 − 营业外支出。
- 合规净利 = 考核净利 − 专项支出 − 所得税。
- 所得税 = `max(考核净利 + 无票费用（cost_belong=5）− 专项支出（cost_belong=4）, 0) × 15%` + 采集策略中归属为所得税（cost_belong=6）的科目金额。
- 国内应交增值税 = 销项税额 − 进项税额（成本）− 进项税额（返利成本）− 进项税额（费用）。跨境（`country_type=2`）不通过该公式系统计算，默认 `0`；如有税额，取业务导入的科目数据。
- 水利基金 = 国内 `[V2 不含税收入 + 凭证主营业务收入 + 凭证其他业务收入] × 0.05%`；跨境为 0。
- 印花税 = 国内 `[V2 不含税收入 + 凭证主营/其他业务收入 + 凭证主营业务成本 + V2 不含税成本 + 返利成本] × 0.03%`；跨境为 0。

跨境收入成本导入表当前没有退款金额、退款数量及退款成本数据；老板报表对该导入来源的跨境退款按 `0` 处理。此规则不覆盖发货 V1 已接入的自研跨境退款 Index。

## 关键字段编码

`EP` 编码与财务科目编码的权威业务口径，取自《T+1净利核算表.xlsx》可见 Sheet「费用名称字典表V6.4.9.3」。下表仅摘录当前已确认的常用映射；不以 DDL 注释或其他科目关系资产替代该字典。

| 编码 | 含义 | 对应科目 |
|---|---|---|
| `EP001` | 含税销售收入（已减退款） | 见「费用名称字典表V6.4.9.3」 |
| `EP028` | 国内不含税收入 | `6001.01` |
| `EP040` | 不含税海外销售收入 | `6001.02` |
| `EP003` | 不含税成本 | `6401.01` |
| `EP041` | 不含税海外销售成本 | `6401.02` |
| `EP042` / `EP043` | 关税成本 / 头程费用成本 | `6401.20` / `6401.21` |
| `EP029` | 销项税额 | `2221.01.01` |
| `EP030` / `EP039` | 成本进项税额 / 返利成本进项税额 | `2221.04.01.01` / `2221.04.01.03` |
| `EP031`~`EP037` | 卖家运费、仓储服务费、包材费用及费用进项税额 | 见「费用名称字典表V6.4.9.3」 |
| `EP038` | 不含税返利成本 | `6401.19`；取发货 V1 返利金额并乘 `-1` 写入 V2，例如 V1 为 `200`，V2 为 `-200` |
| `EP039` | 返利成本进项税额 | `2221.04.01.03`；取发货 V1 返利成本进项税额并乘 `-1` 写入 V2；跨境税额为 `0` |

### 发货 V1 直接费用映射

仅取系统单范围的订单，并按子单粒度汇总：

| 净利费用编码 | 费用含义 | 发货 V1 字段 |
|---|---|---|
| `EP031` | 不含税销售费用_卖家运费 | `no_tax_logistics_cost_fee`（预估物流费用） |
| `EP032` | 不含税销售费用_仓储服务费 | `no_tax_agent_delivery_fee`（预估代发费） |

这两项不经费用采集策略转换。

## V2 分摊要点

- 国内非产销：发货 V1 关联 `dp_dws.doris_dws_srm_purchase_num_percentage_mid`，按商品的供应商采购占比拆分。无采购占比时的兜底分配规则，当前文档未定义。
- 跨境：使用 `tmp_data.abroad_production_revenue_profit`，仅跨境平台店铺；`shipping_date`、`goods_code`、`reserved_field1` 分别映射 V2 的 `dt`、`sku_code`、`plat_spu_id`。导入的 `EP001/EP003/EP042/EP043` 分别进入海外收入、海外成本、关税、头程成本编码。
- 人工、集团管理及其他上传费用：优先取同月上传金额；无金额时按费比；同月费用未上传时使用历史最新月份金额/费比并按目标月天数摊日。
- `tmp_data.other_expense_data`：以 `cost_type`（费用名称）关联「费用名称字典表V6.4.9.3」的费用名称，取得 `expense_code` 后写入 V2。
- 业务多维导入和跨境导入均须按店铺补齐事业群、货主、平台与跨境标识；跨境不能默认国内。
