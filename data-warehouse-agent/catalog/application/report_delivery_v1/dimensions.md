# 发货 V1 维度规则

- 店铺、平台、部门、公司、货主、SKU/货品、类目、供应商、仓库功能、达人、品牌等维度由各订单 Index 及维表补充。
- 平台维表：`dp_dim.doris_dim_platform`，以 `dt + shop_plat_code → dt + plat_code` 关联，`cbs_platform` 标识是否跨境平台（`0` 否、`1` 是）。用于平台属性及是否跨境平台。
- 国别：系统订单默认中国/国内；分销发货按退税标识或店铺跨境属性区分；跨境订单按店铺所属平台判断。跨境平台国别为空，非跨境平台为 `CN`。文档中按收件国别的旧规则为删除线，不采用。
- 停止下单品：2024-11-14 前按“是否停止下采购单=1”或商品前缀 `[TZXD` / `XC-[TZXD`；其后仅按商品名称前缀标记。
- 达人：存在 `author_id` 时展示达人；空、`0` 或无达人 ID 时按规则展示店铺或“未知”；自播/分销由达人扩展属性及空达人 ID 规则判断。
- 体积：代发仓使用 SKU 代发包装尺寸，其他/空仓库功能使用邮购箱尺寸，再乘 V1 销售数量；跨境同规则。
- 产销结算店铺及结算店铺名称在文档中标记“待开发”。
