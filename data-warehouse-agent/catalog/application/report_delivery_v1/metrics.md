# 发货 V1 指标口径

## 核心公式

| 指标 | 汇总口径 |
|---|---|
| 销售数量 | 系统订单发货数量 + 分销发货数量 − 退货应收入库 − 无单退货入库 − 退货实收入库 − 分销退货入库 + 跨境发货数量 − 跨境退货数量 |
| 退货数量 | 退货应收入库 + 无单退货入库 + 退货实收入库 + 分销退货入库 + 跨境退货数量 |
| 销售收入 | 国内系统/分销发货收入 − 系统/分销退款收入 + 跨境收入及差异补充 + 产销主营业收入 |
| 已发货退款收入 | 系统退单退款收入 + 分销退货退款收入 + 跨境已发货退款收入 |
| 未发货退款收入 | 系统退单未发货退款收入 + 分销退货未发货退款收入 + 跨境未发货退款收入 |
| 销售品牌供货成本 | 系统/分销发货供货成本 − 系统/分销已发货退款供货成本 + 跨境发货成本 − 跨境退单成本 |
| 销售采购成本（含税/不含税） | 国内系统/分销发货采购成本 − 国内系统/分销退款采购成本 + 跨境、差异表补充 − 跨境退款成本 |
| 净利成本（含税/不含税） | 国内系统/分销发货净利成本 − 国内系统/分销退款净利成本 + 跨境发货净利成本 − 跨境退款净利成本 |
| 不含税成本（返利） | 系统订单返利成本 − 系统退单返利成本 + 分销发货返利成本 − 分销退单返利成本 |
| 进项税额（成本返利） | 系统订单返利进项税额 + 分销发货返利进项税额 − 系统退单返利进项税额 − 分销退单返利进项税额 |

## 国内订单统一筛选

| 场景 | 时间字段 | 主要限制 |
|---|---|---|
| 系统订单发货 | 发货时间 | 订单功能 `1,2,8`；销售模式 `2,3,4,6,7`；已发货；一般交易订单须有销售出库单 |
| 分销发货 | 发货时间 | 订单功能 `1`；销售模式 `7,8,9`；已发货 |
| 系统已发货退款 | 商家退款时间 | 订单功能 `1,2,8`；销售模式 `2,3,4,6,7`；原订单已发货；平台退款成功；线下平台另按非取消规则处理 |
| 分销已发货退款 | 退款申请时间 `apply_time` | 售后业务类型=退货；原订单已发货；退款状态非取消 |
| 退货入库数量 | 完成时间 | 由库存出入库 Index 按退货应收、无单退货、退货实收、分销退货入库类型汇总；后两类按文档限制关联单号为空 |

## 使用字段（国内）

| 来源 | 数量/收入 | 成本、税额 |
|---|---|---|
| 系统订单商品 Index | 发货数量、`payment` | `brand_quotation`、采购成本、`product_cost`、`no_tax_product_cost`、返利成本及进项税额 |
| 分销发货 Index | `delivery_num`、`delivery_amount` | 供货、采购、净利、返利成本及进项税额 |
| 系统退单 Index | `refund_fee` | 供货、采购、净利、返利成本及进项税额 |
| 分销退货 Index | `apply_refund_amount` / `actual_return_amount` | `cost_price`、`purchase_price_total`、`product_cost`、`no_tax_product_cost`、返利成本及进项税额 |
| 出入库 Index | 入库正品数量 + 入库残品数量 | 用于退货数量抵减 |

跨境差异历史数据已确认经 `doris_ods_eb_trade_order_tmp → doris_dws_eb_trade_order_goods_index` 进入 V1。国内销售的含/不含税订单收入、销项税额、成本进项税额及卖家运费、代发费相关税额，均直接汇总销售模块的商品级字段；不以费用采集策略表作为前置来源。

## DDL 口径优先级

`doris_app_report_delivery_v1` DDL 已给出 `sales_amount`、`input_tax_amount` 等字段的最终组合公式。说明文档中的两版销售收入描述和进项税额段落的“销项税额”文字，均以 DDL 字段注释为准。
