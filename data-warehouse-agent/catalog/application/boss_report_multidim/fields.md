# 老板报表字段与规则（可见 Sheet 解析）

## 全局时间与展示规则

- 近 30 日：包含昨日的 30 天；本月：当月 1 日至昨日；财年：最近的 4 月 1 日至昨日。
- 默认业态展示 TOB/TOC；销售模式 `1`、`-1` 及新增销售模式归入“其他”。
- 金额单位：集团、部门、渠道、店铺为万元并保留两位；其余页面和抽屉趋势为元并保留两位。
- 最新可见净利规则以 2026-04-01 为分界：此前查询走旧逻辑，此后走 V2/科目分摊/产销导入的新价税分离逻辑；跨期窗口按查询开始时间划分。

## 页面字段组

| 页面/场景 | 主要字段或指标 | 已确认来源/口径摘要 |
|---|---|---|
| 集团、部门、渠道、店铺 | 收入、自研收入、收入占比、考核净利、合规净利、税额 | 国内主要取发货 V1（`country_code='CN'`）；跨境上月、财年、近 365 日主要取净利 V2 的跨境导入 `EP001`；产销取导入表 |
| SKU、货品、品类、达人、平台链接 | 收入、销量、采购成本、毛利率、净利及净利弹窗 | 实时支付取实时表；历史发货取 V1；净利由 V2、科目分摊成功/失败表、产销导入及业务净利应用表共同组成 |
| 清仓品 | 库存、去库存金额、销量、收入、采购成本、毛利率、可发天数 | 库存表 + 动销维表；销售仓优先月度不含税成本，代发仓取不含税含运采购价 |
| 库存与周转 | 库存金额、可发天数、实际日销、7/14 日销量 | `doris_dws_sku_stock_index`、`doris_dws_stock_turnover_index`；日销为 7 日 60% + 14 日 40% 加权 |
| 人力成本占比 | 部门人力成本 / 特定口径收入或产值 | 人力成本表与 V1、V2、产销导入收入按部门配置组合；部门清单见 `DAS v5.8.6人力成本占比` |

## 周转天数 / 可发天数

> 来源：《老板报表应用产品.xlsx》可见 Sheet「DAS v5.8.6老板报表指标」第 23、49、132 行。

`周转天数 = CEILING(总库存数量 ÷ 加权日均出库数量)`。

`加权日均出库数量 = 近 7 日商品销售出库数量 ÷ 7 × 60% + 近 14 日商品销售出库数量 ÷ 14 × 40%`。

- 国内：限制销售仓、代发仓；按商品或货主口径取总库存（`all_stock`）和日均出库量（`avg_daily_sales_qty`，库存表日销字段为 `yst_delivery_num`）。
- 跨境：库存销量按导入数据拆分到每天后作为日均出库量。
- 总库存为 `0` 时，周转天数为 `0`。
- 总库存非 `0` 且加权日均出库量小于等于 `0` 时，周转天数为无穷大。
- 总库存大于 `0` 且加权日均出库量大于 `0` 时，按上式向上取整。

## 价税分离净利字段

| 字段 | 规则 |
|---|---|
| 含税收入 | V2 `EP001` + 科目分摊收入/销项税额 + 产销导入含税收入；按科目 `is_tax` 决定取 `tax_amount` 或 `no_tax_amount` |
| 主营业收入/成本 | 采集策略 `cost_belong=1/2` 的五类来源汇总；展示科目含 `6001`、`6401` 及其子科目 |
| 税金及附加 | 采集策略 `cost_belong=7`；含附加税、水利基金、印花税 |
| 销售费用 | 采集策略 `cost_belong=3` |
| 应交税费 | 采集策略 `cost_belong=10`；展示销项及成本/返利/费用进项税额、应交增值税 |
| 考核净利 | 不含税收入 − 成本 − 费用 − 税金及附加 + 营业外收入 − 营业外支出 |
| 合规净利 | 考核净利 − 专项支出（`cost_belong=4`）− 所得税（`cost_belong=6`） |

跨境 `country_type=2` 的应交增值税不由系统公式计算，默认 `0`，有税额时取业务导入的科目数据。跨境收入成本导入表当前无退款数据，老板报表在该来源上按退款 `0` 处理；不影响发货 V1 已接入的自研跨境退款事实。

## 已明确的筛选与隐藏

- 集团、部门、店铺、品类、货品、SKU 页面均有业态、国别等筛选；详情见 Sheet「额外说明」。
- 多个页面已要求隐藏含税毛利率，并将“不含税毛利率”前端名称调整为“毛利率”。
- 毛利率新口径：`1 - 近30日返利后成本 / 近30日不含税收入`；国内使用 V1，跨境收入优先取 V2 `EP040`。
