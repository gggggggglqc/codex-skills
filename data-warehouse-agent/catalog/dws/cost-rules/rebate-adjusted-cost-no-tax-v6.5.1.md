# 返利后成本（不含税）规则 — V6.5.1

## 口径状态

最新 Excel 的“系统订单/分销订单/分销发货单商品采购成本（不含税）”均为局部删除线历史文本，不作为当前指标。“返利后成本（不含税）”是**计算过程中的中间金额**：选定不含税单价乘业务数量，用于派生返利成本金额等指标，不要求在三张 Index 中独立落字段。

不得将该中间金额映射为 `no_tax_purchase_price_total`，也不得新增“返利后成本”字段。

## 强制来源边界

| 数据类型 | 唯一可用来源/字段 |
|---|---|
| 返利后成本 | `srm_billing.purchase_cost_price` 的 `purchase_cost_price` 或 `cost_price`；二者分支取值待 SQL 定版 |
| 成本价兜底 | `dp_dim.doris_dim_stock_cost.cost_price` |
| 融合采购价兜底 | `dp_dim.doris_dim_sku_cost_price.no_tax_freight_price`，且 `cost_type = 2` |

## 系统订单商品

### 已发货

1. 按仓库所在区域、货主、商品、发货月份查询 `purchase_cost_price`；无当月记录取最新月份返利后成本，多条取最高价。
2. 空或 0 时，按仓库所在区域、商品、发货时间查询 `stock_cost.cost_price`，取上月已关账成本价，多条取最高价。
3. 空或 0 时，按仓库所在区域、商品、发货时间查询融合表；再按商品、发货时间查询融合表。取 `no_tax_freight_price`，商品级匹配取最近生效价，多条取最高价。
4. 仍为空或 0 时，单价为 0；总额乘系统订单下单数量 `num`。

### 未发货

1. 按货主、商品、支付时间所在月份查询 `purchase_cost_price`，取最新返利后成本。
2. 空或 0 时，按商品、支付时间查询融合表 `no_tax_freight_price`，取最近生效价，多条取最高价。
3. 仍为空或 0 时，单价为 0；总额乘系统订单下单数量 `num`。

## 分销订单商品

1. 按仓库所在区域、货主、商品、创建月份查询 `purchase_cost_price`；无当月记录取最新月份返利后成本，多条取最高价。
2. 空或 0 时，按仓库所在区域、商品、创建时间查询采购成本表返利后成本，多条取最高价。
3. 空或 0 时，依次按仓库所在区域、商品、创建时间及商品、创建时间查询融合表 `no_tax_freight_price`；商品级匹配取最近生效价，多条取最高价。
4. 仍为空或 0 时，单价为 0；总额乘分销订单下单数量 `num`。

## 分销发货单商品

1. 按仓库所在区域、货主、商品、发货月份查询 `purchase_cost_price`；无当月记录取最新月份返利后成本，多条取最高价。
2. 空或 0 时，按仓库所在区域、商品、发货时间查询采购成本表返利后成本，多条取最高价。
3. 空或 0 时，按商品、发货时间查询上月已关账 `stock_cost.cost_price`，多条取最高价。
4. 空或 0 时，依次按仓库所在区域、商品、发货时间及商品、发货时间查询融合表 `no_tax_freight_price`；商品级匹配取最近生效价，多条取最高价。
5. 仍为空或 0 时，单价为 0；文档写“已乘发货数量”，即应乘 `delivery_num`。
