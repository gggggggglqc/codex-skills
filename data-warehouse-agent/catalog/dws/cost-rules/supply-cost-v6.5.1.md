# 供货成本规则 — V6.5.1

## 输出映射

| 业务事实 | 有效指标 | DWS 字段 | 数量基数 |
|---|---|---|---|
| 系统订单商品 | 商品供货成本（财务口径） | `brand_quotation` | 下单数量 `num` |
| 系统订单商品 | 商品预估供货成本 | `estimate_brand_quotation` | 下单数量 `num` |
| 分销订单商品 | 商品供货成本（财务口径） | `estimate_brand_quotation` | 下单数量 `num` |
| 分销发货单商品 | 商品供货成本（财务口径） | `brand_quotation` | 发货数量 `delivery_num` |

## 取价来源约定

- 品牌供货价-标准价：`dp_dim.doris_dim_sku_cost_price.brand_quotation`。
- 采购价格（不含税含运费单价）：`dp_dim.doris_dim_sku_cost_price.no_tax_freight_price`，`cost_type = 2`。
- 每个分支的结果均以选定单价乘本表数量基数。

## 系统订单商品供货成本（财务口径）

按系统订单发货时间取价，优先级如下：

1. `商品编码 + 发货时间`：查询**西安仓**的品牌供货价-标准价。
2. 未取到时，`订单仓库 + 商品编码 + 发货时间`：查询对应品牌供货价-标准价。
3. 未取到时，`仓库所在区域 + 商品编码 + 发货时间`：查询采购价格（不含税含运费单价）。
4. 仍未取到时，单价为 0。

总额写入 `brand_quotation`，乘系统订单下单数量 `num`。

## 系统订单商品预估供货成本

### 已发货

1. `订单仓库 + 商品编码 + 发货时间`：查询对应品牌供货价-标准价。
2. 若订单仓为**京仓委外仓**（`WH0026`），品牌供货单价改取**航天自营仓**（`WH0009`）对应的品牌供货单价。
3. 未取到时，`仓库所在区域 + 商品编码 + 发货时间`：查询采购价格（不含税含运费单价）。
4. 仍未取到时，单价为 0。

### 未发货

按系统订单商品，在订单当天的各仓品牌供货价-标准价中取**最高单价**；未取到时为 0。

总额写入 `estimate_brand_quotation`，乘系统订单下单数量 `num`。

## 分销发货单商品供货成本（财务口径）

按分销发货单发货时间取价，优先级如下；每一层多条记录均先取 `price_start_time` 最晚，开始时间相同再取价格最高的一条。

1. `商品编码 + 发货时间`：查询**西安仓**（`SH001`）的品牌供货价-标准价。
2. 未取到时，`订单仓库 + 商品编码 + 发货时间`：查询对应品牌供货价-标准价。
3. 未取到时，`仓库所在区域 + 商品编码 + 发货时间`：查询采购价格（不含税含运费单价）。
4. 仍未取到时，单价为 0。

总额写入 `brand_quotation`，乘分销发货数量 `delivery_num`。

## 分销订单商品供货成本（财务口径）

按分销订单创建时间取价，优先级如下；每一层多条记录均先取 `price_start_time` 最晚，开始时间相同再取价格最高的一条。

4. 仍未取到时，单价为 0。

总额写入 `estimate_brand_quotation`，乘分销订单下单数量 `num`。
