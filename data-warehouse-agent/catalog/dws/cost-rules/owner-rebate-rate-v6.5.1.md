# 货主返利比率规则 — V6.5.1

## 输出字段

三张销售 Index 的返利比率字段均为 `rebate_rate`。

## 规则

- 系统订单和分销发货：按“货品编码 + 货主编码 + 发货时间所在月份”查询 `dim.owner_markup_rule`，取 `rebate_rate`。
- 分销订单：按“货品编码 + 货主编码 + 创建时间所在月份”查询。
- 分销退货：按“货品编码 + 货主编码 + 退款申请时间所在月份”查询，归售后模块补充。
- 无匹配时，返利比率为 0。

## 来源

- 产品口径：`销售模块.xlsx` → `基础指标-商品v6.5.1`，第 24、65、71 行。
- 物理表：`dp_dim.doris_dim_owner_markup_rule`。
