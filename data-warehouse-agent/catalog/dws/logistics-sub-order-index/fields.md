# 字段与规则（子单粒度）

除原始子订单、SPU/SKU/商品编码、商品数量，以及子单预估物流费/代发费外，其余主单字段与规则继承 `dws.logistics_order_index`。

## 子单费用分摊

按出库单子单的商品总体积占比，分摊主单物流费和代发费。

1. 每个商品总体积 = 单品体积 × 商品数量；以出库单内所有商品总体积求和为分母。
2. 子单分摊物流费 = 子单总体积 ÷ 全部总体积 × 主单物流费。
3. 子单分摊代发费 = 子单总体积 ÷ 全部总体积 × 主单代发费。
4. 某商品无体积时不承担费用，费用由其他有体积商品承担。
5. 仅一个商品时，子单费用 = 主单费用。
6. 子单数量大于 1 且所有商品体积均计算失败时，子单费用 = 主单费用 ÷ 子单数量。

## 新增依赖

combine 表需新增 `weight`、`sub_agent_delivery_fee`、`sub_logistics_cost_fee` 字段；前两项子单费用字段由上述体积分摊规则计算。
