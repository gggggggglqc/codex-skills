# 售后模块场景梳理与差异待办 — V6.5.1

## 当前范围

售后模块覆盖五类已接入场景，另有两类待接入场景：

| 场景 | 当前业务对象 | 主要指标 |
|---|---|---|
| 原始退单 | OMS 原始退单、原始退单子单 | 申请数量、退回买家金额、其他退回金额；关联原始订单数量/已付 |
| 系统退单 | OMS 系统退单、系统退单子单 | 退款数量、退款金额；关联系统订单数量、费用与成本 |
| 售后补发 | 系统订单及子单 | 下单/实发、邮费、成本；补发建单/出库动作 |
| 分销退单 | DMS 分销退单及子单 | 申请退款数量、申请退款金额 |
| 分销退货单 | DMS 分销退货单及子单 | 申请/实收/退货数量金额、供货成本、采购/净利成本 |

待接入：班牛包裹拦截、补偿退款、催件工单。

## 已能复用销售模块的规则

| 售后指标/关系 | 复用来源 |
|---|---|
| 系统退单关联系统订单子单 | 系统退单子单的系统订单子单号；关联异常时，按原始子订单号 + 商品编码补关联 |
| 系统退单商品供货成本 | 系统订单 Index 的预估品牌供货成本，按退单数量比例取值 |
| 系统退单商品采购/净利成本 | 系统订单 Index 总成本 ÷ 下单数量 × 退单退款数量 |
| 退单返利比率 | `spu_code + owner_code + 发货月份 → dp_dim.doris_dim_owner_markup_rule.rebate_rate`，无匹配为 0 |
| 退单返利成本与返利进项税额 | 沿用销售模块的一般纳税人/小规模/个体户分支；数量基数为退单退款数量 |
| 售后补发成本及费用 | 与系统订单对应成本及商品级包材、预估物流、实际物流费用分摊规则一致；通过系统子单关联获得 |
| 公司税率与公司性质 | `dt + shop_code → dim_shop.company_code → dim_company`；店铺禁用或未绑定公司时税率为 0 |
| 分销退货财务供货成本 | 西安仓 `SH001` 品牌供货价 → 订单仓品牌供货价 → 仓库区域不含税含运费采购价；多条先取开始时间最新，再取最高价 |

## 售后特有规则

- 退货应收入库单决定 OMS 原始/系统退单的商家收货状态；已确认主单 `return_order` 与子单 `sub_refund_stock_order`，主单提供 `order_status`、到货/完成时间，子单提供申请/实收/收货数量。
- 分销退货存在影刀账号 `1810592227250778112` 特殊分支：自 4 月 1 日起常规分销退货单剔除影刀数据；影刀数据改取分销退单，且限制退单状态 `refund_status = 60`（已收货）。
- 分销退货的申请、发货、收货三个动作分别使用退款申请时间、退货发货时间、收货时间作为业务时间。
- 分销退货的供货/采购/净利成本按收货仓库功能分支，涉及销售仓、暂存仓、代发仓、委外仓及仓库区域。已确认分销退单主单和退货入库主单，但两者均非商品级实收成本来源。
- 售后补发订单直接通过系统订单 `order_category` 识别，不建立班牛补发单或补发出库单的溯源链路。商品级包材、预估物流、实际物流费用直接沿用系统订单既有分摊规则。

## 与销售模块的关键差异

| 主题 | 销售模块 | 售后模块 |
|---|---|---|
| 业务时间 | 下单、支付、发货等正向订单时间 | 申请、退货、收货、退款、补发建单/出库等多动作时间 |
| 数量基数 | 下单数量、发货数量 | 退单退款数量、申请退款数量、实收数量、退货数量 |
| 成本处理 | 正向订单总成本 | 正向成本按退货数量比例还原，或按退货仓功能重新取价 |
| 状态判断 | 订单/发货状态 | 增加售后阶段、售后动作、商家收货状态、原始/系统/分销退单状态 |
| 特殊数据 | 无 | 影刀账号替代取数、退货应收入库、班牛工单待接入 |
