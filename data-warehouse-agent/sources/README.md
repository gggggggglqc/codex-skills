# 来源材料管理

`sources/` 保存可复用、可审阅的来源证据，不保存业务明细、账号、密钥或未经脱敏的导出数据。

| 目录 | 内容 | 是否纳入 Git |
| --- | --- | --- |
| `ddl/` | 已确认的 DDL、字段说明、结构快照 | 是 |
| `product/` | 已转换为 Markdown 的产品规则、说明材料 | 是 |
| `raw/` | CSV、XLSX、DOCX 等原始文件或结果数据 | 否 |
| `register.yaml` | 来源 ID、位置、状态、适用范围 | 是 |

新增来源时：先在 `register.yaml` 登记来源 ID、类型、路径、定位信息与状态；可公开复用的规则材料转为 Markdown 后放入 `product/`；原始数据放入 `raw/`，仅保留路径与证据说明。
