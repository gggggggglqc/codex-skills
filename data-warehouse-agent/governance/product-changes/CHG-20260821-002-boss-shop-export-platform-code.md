## 2. 产品需求

### 需求背景

店铺简称可能重名。仅按店铺简称查看“净利导出”或“列表导出”时，无法区分所属平台。

### 规则调整

在店铺报表的以下导出结果中，新增 `平台编码` 列，用于与店铺简称共同识别店铺：

1. 净利导出；
2. 列表导出。

平台编码展示原始编码值，不使用平台名称替代；不改变现有店铺简称、店铺编码、收入、净利等字段的取数和排序。

### 影响范围

| 范围 | 调整 |
| --- | --- |
| 店铺报表净利导出 | 新增平台编码列 |
| 店铺报表列表导出 | 新增平台编码列 |
| 页面列表、抽屉、其他报表导出 | 本需求不调整 |

## 5. 上线验收

1. 净利导出和列表导出均含 `平台编码` 列。
2. 同一店铺简称、不同平台编码的记录可明确区分。
3. 平台编码与店铺实际所属平台一致。
4. 现有导出列、导出权限、排序与金额口径不发生变化。
