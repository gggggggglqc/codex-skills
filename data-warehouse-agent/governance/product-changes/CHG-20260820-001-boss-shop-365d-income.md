## 2. 产品需求

### 需求背景

老板报表需要展示近 365 天有收入的店铺。原有“近 365 天收入”的表述未明确国内发货与跨境收入的合并口径，可能导致仅有跨境收入的店铺无法展示。

### 规则调整

近 365 天店铺累计收入：

```text
发货 V1 收入 + 跨境净利 V2 中 EP001 收入
```

当累计收入 `> 0` 时，展示店铺信息；累计收入 `<= 0` 或无收入时，不展示。

该条件只决定店铺是否展示，不改变既有收入、成本、净利等指标的计算口径。

### 影响范围

| 范围 | 调整 |
| --- | --- |
| 店铺信息与店铺监控 | 按上述合并收入判断是否展示 |
| 店铺数量、列表、抽屉 | 同一统计周期、同一收入判定口径，结果一致 |
| 集团、部门、渠道等其他汇总指标 | 不调整其既有收入、成本、净利计算 |

## 3. 历史数据处理

## 5. 上线验收

1. 发货 V1 收入大于 0、跨境 V2 EP001 为 0 的店铺，应展示。
2. 发货 V1 收入不大于 0、跨境 V2 EP001 大于 0，且合并收入大于 0 的店铺，应展示。
3. 合并收入等于 0、负数或无收入的店铺，不展示。
4. 同一日期范围内，店铺数量、店铺列表及抽屉中的店铺集合一致。
5. 既有收入、成本、净利指标值不因本需求发生变化。
