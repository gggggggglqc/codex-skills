## 2. 产品需求

### 需求一：毛利率展示统一

所有报表的字段展示和抽屉列表：

1. 不展示“含税毛利率”；
2. 将“去税毛利率 / 不含税毛利率”统一展示名称为“毛利率”；
3. “毛利率”的数值口径与对应列表指标一致，不因页面或抽屉不同而改变。

已确认的毛利率公式为：

```text
毛利率 = 1 - 返利后成本 / 不含税收入
```

国内使用发货 V1 的返利后成本、不含税收入；跨境不含税收入优先取净利 V2 的 `EP040`。具体时间窗口、销售货品等既有限制沿用对应列表规则。

### 需求二：指定抽屉收入与列表一致

除部门、店铺外，以下报表的抽屉中 `SKU、货品、品类、平台链接` 收入字段，统一沿用各自主列表在相同时间范围、筛选条件下的收入规则：

| 报表 | 抽屉明细范围 |
| --- | --- |
| SKU 报表 | SKU、货品、品类、平台链接 |
| 货品报表 | SKU、货品、品类、平台链接 |
| 品类报表 | SKU、货品、品类、平台链接 |
| 平台链接报表 | SKU、货品、品类、平台链接 |

现有文档已明确主列表在上月、财年、近365日的收入：国内取发货 V1，跨境取导入 / 净利 V2 的 `EP001`；本需求要求抽屉不再使用与主列表不一致的独立收入逻辑。部门与店铺报表明确不在本次收入优化范围内。

## 7. 待确认事项

1. “所有报表”是否包含清仓品、供应商、达人、渠道等页面的抽屉；当前按所有页面隐藏/改名理解，但收入优化仅覆盖 SKU、货品、品类、平台链接。
2. 达人报表在历史文档 `DASv5.8.6净利优化!F4` 中被列入收入优化范围，但本次版本说明未提及；是否继续纳入本期抽屉收入优化需确认。
3. 指定抽屉收入优化是否覆盖昨日、近3/7/30日、本月，还是仅覆盖上月、财年、近365日；现有跨境 V2 / 导入口径主要在后者明确。
4. 平台链接跨境收入应继续使用 `abroad_production_revenue_profit` 的链接级数据，还是统一改为净利 V2 `EP001`；两者粒度不同，不能默认替换。
