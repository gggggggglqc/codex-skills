## 不纳入 Git 的材料

| 类型 | 存放位置 | 原因 |
| --- | --- | --- |
| 原始 CSV/XLSX/DOCX 与结果明细 | `sources/raw/` | 可能含业务明细、体积大且无法稳定做文本审阅 |
| 临时编辑器、系统文件 | `.DS_Store`、`*.tmp`、`*.bak`、`*.swp` | 与知识规则无关 |
| 本机环境标识 | `.codex-windows-source.txt` | 不属于团队共享知识 |

## 入库判定

满足以下条件才可纳入 Git：内容可被团队复用；不含敏感明细或密钥；有来源、适用版本和确认状态；可通过 Markdown、YAML、SQL 或脚本进行差异审阅。

原始文件中的规则需要入库时，先转写为可审阅的 Markdown / YAML，并在 `sources/register.yaml` 中保留原始来源路径和定位信息。
