# 数仓数据资产库

本仓库保存产品侧可确认的数据资产：表、字段、指标口径、计算公式、实现映射、需求与核查规则。

## 分层顺序

`ODS（原始数据） → DWD/DWS（明细/汇总） → APP（应用指标）`

当前先建设 ODS：每张表先完成表级资产，再由可靠的表结构或数仓开发确认补充字段。没有证据的字段不得推断。

## 权威规则

- 业务口径是产品确认后的业务准则。
- 数仓 SQL/表结构是数据实现证据；DAS 代码是应用实现证据。
- 任一来源冲突时，资产状态应为 `待核验`，不能自行覆盖历史版本。
- 所有变更通过 Git 提交保存；资产内记录生效版本、来源和确认状态。

## 目录

- `catalog/ods/`：ODS 表资产与字段资产。
- `schemas/`：机器可校验的资产字段约束。
- `templates/`：新增资产、变更、核查规则模板。
- `governance/`：版本、状态和协作规则。
- `agents/`：六类数仓与数据应用 Agent 的输入、输出与权限边界；当前可用入口为文档版本管理、数据核对、指标口径与影响分析、数据研发设计、数据质量与调度运营、数据排查与应用诊断、数据产品需求闭环，产品设计见 `agents/product-design.md`。
- `sources/`：来源登记；原始大文件不纳入 Git。

## 当前范围

首个场景为“老板报表与 T+1 净利”。首批 ODS 表仅为已在现有产品文档或 DAS 代码中发现引用的候选资产，待补充数仓正式建表语句、字段清单与负责人确认。

销售模块的建设进度与未闭环事项见 `governance/open-items.md`；在该清单关闭前，每次资产处理均须报告剩余问题。
