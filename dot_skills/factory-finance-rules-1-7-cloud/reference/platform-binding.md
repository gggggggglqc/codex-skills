# 平台接入与验证

当前包是平台中立的单文件运行时。参考v3提到的query_sql、python、uploadOssFile及其固定地域/实例属于参考环境，不证明目标环境具备同名工具，也不作为本技能连接配置。

## 接入前记录

记录真实Python工具名、输入参数、完整代码长度、输入输出上限、标准库可用性、硬超时和内存配额；用完整源码+`run({...})`做一次最小调用。若源码不允许单次传入且文件也不可读，停止并报告不支持。

记录SQL工具名、实例/地域选择方式、db_name参数、跨erp_iom/mes_aps/erp_cost权限、成功/错误/截断/分页的原生字段与行响应结构。保留一次SELECT常量的原始响应样例和状态映射证据。对没有可靠“不截断且无后续页”契约的工具，不允许智能体补false。

记录上传工具的文本参数、编码、大小、URL字段与权限。没有上传能力仍可返回已验证结构化结果，不声称已导出。机器人发送能力独立配置，不能将本地自动发送偏好迁移成云端自动授权。

## 实际联调顺序

1. Python最小输入、空结果解析、错误回执拒绝。
2. SQL最小只读查询验证状态映射；确认跨库关联权限。
3. 用短日期窗口选择一条规则完成plan→SQL→consume→finalize；确认validation全部一致。
4. 验证错误、截断和分页停止；测试真实工具输出大小。
5. 若需要文件，render_csv→上传→实际链接可访问。
6. 在独立验收任务验证整月规模、数据一致性和并发，不由本地协议测试替代。

只读SQL冒烟仍应由目标环境的授权连接执行，不能在Python中读取凭据或改用网络直连来“完成联调”。保存已验证/未验证清单。真实端到端未完成时，只能说“迁移代码已交付、云端联调待验证”，不得标记生产就绪。
