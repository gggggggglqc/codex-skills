# 工厂财务1–7数据核对

按月核对生产入库、生产成本、委外加工和领料数据，汇总每条规则的核对结果，列出差异物料或单据明细。支持执行全部1–7规则，也支持只复核其中几条规则。

## 核对范围

| 规则 | 核对内容 |
| --- | --- |
| 1 | 完工入库数量与调整后的报工入库数量 |
| 2 | 完工入库数量与实际成本还原的完工入库数量 |
| 3 | 完工入库数量与生产成本管理的生产入库数量 |
| 4 | 完工入库成本单价×数量与实际成本还原的生产成本金额 |
| 5 | 完工入库成本单价×数量与生产成本管理的实际生产入库金额 |
| 6 | 实际委外加工费用与财务委外加工明细金额 |
| 7 | 领料出库数量与倒冲领料数量，按基本单位比较 |

## 执行前确认

从用户表述和已有上下文取得明确年份、月份及规则范围。月份按首日至末日展开，默认执行全部规则；用户要求“再核对2–6”等复核时沿用已明确的月份。仅在无法唯一确定时一次询问缺失信息。

业务日期按Asia/Shanghai解释。成本核对的业务范围必须位于同一成本月份，最多31天。默认完工入库按账务日期、报工按创建日期核对；默认报工数量使用关联完工入库明细调整后的数量，不能将结果表述为独立原始报工量一致。用户明确要求其他已支持口径时，在结果中注明。

## 核对步骤

1. 读取[规则口径](reference/rules.md)，确认时间、数量、金额、状态过滤与基本单位。
2. 按[内部执行规程](reference/execution.md)完整获取并验证所选规则的数据。规则、范围或数据完整性有疑问时停止，说明原因，不使用部分结果得出结论。
3. 按物料或关联明细比较数量、金额，分别列出数值差异、单边缺失和单位/关联异常。
4. 汇总各规则比较数、差异数、左右总额和净差额；对差异较多的结果，优先展示主要差异，保留完整明细供导出。
5. 用户要求文件时导出汇总与差异明细；要求全部比较记录时按实际规模分片导出。用户要求发送结果且接收目标明确时，再调用已授权的消息工具。

## 结果说明

先说明核对月份、规则范围及总体结论，再按规则展示结果。固定差异方向为左侧减右侧；规则6为成本还原委外费减财务委外金额。跨物料数量合计仅辅助勾稽，未确认单位名称时不标注件或公斤。

- 数量或金额不同：说明差异方向、物料或单据数量，并列出明细。
- 数据为空、单侧缺失：说明“无数据”或“数据不完整”，不能称为通过。
- 成本金额两侧为零：要求业务复核，不能只因零等于零就称为通过。
- 单位、物料或关联异常：单列异常，数量碰巧相等也不能称为通过。
- 查询失败、截断、缺回执、重复业务键或超限：说明核对未完成，不生成业务结论或文件。

规则2/3、4/5分别共用同一成本字段，不作为四组独立证据。金额按原精度、不设容差展示，单价复算尾差不能自动忽略。差异原因需要进一步证据时明确区分已确认事实与待验证原因。
